Playbooks

A playbook carries a student through a process that spans weeks and offices. Each is a declared file in the control plane, is admitted by the factory when every check passes, reads only the grants it declares, and pauses in an explicit unresolved state instead of guessing. Shapes: rectangle, a step to do; diamond, a question; stadium, waiting on someone else; parallelogram, a message the student approves; double box, documents to gather.
