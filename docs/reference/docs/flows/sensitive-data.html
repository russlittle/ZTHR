Sensitive data

Every field the Advocate keeps is classified, and every build proves where the personal, sensitive and secret ones actually go. A unique marker is planted in each such field; a student then uses the app by text, on the web, through the API, with a mentor introduction sent and a webhook registered; and every place data can land is searched for every marker. A marker found anywhere its class may not go fails the sensitive-data gate, naming the field and the place. The latest run is on the factory console's Sensitive data trace page.

The classes

Class Means Fields
public Published facts anyone may read 14
internal Ids, times, statuses and settings that say nothing about the student alone 62

A field may declare one more place for itself, with a reason: the student's first name and the note they approved go to the mentor platform; their class-site token goes to the class site; their webhook address receives webhooks.

How it stays out

flowchart TB
  in[A fact comes in] --> q{Class}
  q -- personal or sensitive --> store[(App store, owned by the student)]
  q -- sealed fact --> sealed[(Sealed store: encrypted per student, opened only by granted identities)]
  q -- secret --> hash[Hashed or encrypted; never shown, not even in the student's export]
  store --> own[Back to the student: screens, texts, export, API]
  store -. approved exact text only .-> out[Sent with approval]
  store -. never .-> ev[(Evidence: keyed-hash subjects, no content)]
  store -. never .-> led[(Consent ledger: short hashes, never labels or names)]
  store -. never .-> adm[App admin and outcomes: counts of five or more only]

Sealed facts

Fact Class Why it is sealed
justice_involvement sensitive Justice history; used only for the fair-chance path when the student asks.
foster_care_history sensitive Foster care history; opens foster-youth aid.
class_site_token secret The student's class-site login token; granted only to the class-site sync.
doc:<keyed hash of the name> sensitive The contents of documents the student keeps; the name itself stays out of the sealed store and the ledger.
