Intent studio

Say what you want in your own words. The studio turns it into a numbered schematic, asks only the few questions that change what gets built, and releases a package a software factory builds to, with the journeys that will prove it works.

How it works, and the source

    1Your words

    Rough is fine: a few lines, a pasted spec, or a page. Metaphors are welcome.

    No model needed: answer these four, and each answer goes straight onto the schematic as yours.

    Or drop a file: Markdown, Spec Kit, Kiro, OpenSpec, Gherkin or an HTML page, a Claude artifact included.

    2Readings

    Two model families read your words independently. Where they agree, it goes on the schematic for you to confirm; where they differ, you get a redline, not a guess.

      Add a reading from another model

      Copy the request, ask another model (Gemini, Llama, any you trust), and paste its answer here. Only the request leaves this page, and only when you paste it somewhere.

      3Redlines: questions to settle

      Each one changes what gets built. Tap an answer; "Other" is always there.

      Keys 1 to 9 choose an option in the question you are on.

      How it works, and the source

      Deterministic first

      Everything on the schematic except a reading is worked out by rule in this page: intake, the checks for gaps and overlaps, the design lexicon, derived rules, tolerances, journeys, the build manifest and the package. The same words always give the same bytes. Models only read, and a single reading is never taken as fact.

      Open formats

      The package is plain files: datum.json, journey gauges in the factory's card format, control-plan.yaml, ratchets.json, build-manifest.json and a knowledge bundle. The formats, field by field.

      Extend it

      The lexicon, the roles, the parts catalogue and the rules that choose parts are data and short rule tables, each tested. How to add a word, a role, a part or a rule.

      Apache 2.0

      The studio, the command line and the engine are one open package. Read the source, run it locally (node src/cli.ts readback intent.md), or contribute.

      Detail

      What leaves this page: your words go to Claude only when you choose "Read with Claude", and to another model only if you paste them there yourself. Everything else (the checks, the schematic and the package) is worked out here, in your browser. Your work is saved to your own private space, which only you can read, or to this browser when that is not available. "Start a new intent" clears it.
