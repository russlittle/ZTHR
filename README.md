# ZTHR: Zero Trust – High Reliability

**A pattern language for autonomous software delivery.**

AI writes the code. The factory proves it. ZTHR describes how to deliver software written by AI without making human code review the thing that holds quality together.

It rests on two principles:

- **Symmetric Zero Trust.** No author, reviewer, model, operator or report gains authority by asserting success. A claim counts only on evidence the claimant does not control.
- **The Fixture Inversion.** Quality moves out of the author's skill and into the environment the author works in. Governed parts constrain what can be built, checks proven to fail on their target defects judge what was built, and protected statements of user intent define what the result must still do. Generators iterate until those fixtures are satisfied.

Thirty-three patterns in six families implement them, from construction through runtime.
